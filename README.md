# Quitting Time

It's 5 PM. Tap cubicles to release the workers and get each one onto their color's shuttle home. Wrong color? They wait in the break room, and it's tiny.

Play it in any browser: open `index.html`, or visit the GitHub Pages link for this repo.

- Endless shifts that get harder as you go: locked meetings, hidden shuttles, fewer chairs
- Performance Reviews every 10th shift, plus a Daily Shift with a streak
- Undo, Coffee and +Chair boosters
- Perks Shop with shuttle skins and worker looks

## Branches

- `main` is the live version on GitHub Pages
- `dev` is for testing changes before they go live
